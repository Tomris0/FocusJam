
# 🎧 FocusJam

**Focus together. Stay in sync.**

FocusJam is a real-time synchronized Pomodoro app that helps people focus together without timer drift.

---

## 🚨 The Problem

When people try to focus together remotely:

* Timers don’t start at the same time
* Breaks don’t match
* The group loses rhythm

Even a few seconds of delay breaks the entire flow.

---

## 💡 The Solution

FocusJam keeps everyone on the same timeline.

* One person starts the session (Host)
* Others join with a simple code
* Everyone follows the same timeline

No countdowns. No confusion. Just focus.

---

## 🚀 Current Status

🛠️ MVP in active development

* Real-time synchronized timer
* Room system (Host / Join with code)
* Firebase-based architecture
* Reconnect system (auto return to session)

---

## 🧠 Vision

FocusJam is not just a timer.

It’s a **shared focus experience**.

Planned features:

* Deep Work Mode
* Sprint Mode
* Team sessions
* Focus analytics

# 🇹🇷 Türkçe

# 🎧 FocusJam

**Birlikte odaklan. Senkron kal.**

FocusJam, insanların aynı anda odaklanmasını sağlayan gerçek zamanlı senkron bir Pomodoro uygulamasıdır.

---

## 🚨 Problem

Uzaktan birlikte odaklanmaya çalışırken:

* Sayaçlar aynı anda başlamaz
* Molalar uyuşmaz
* Grup ritmi bozulur

Saniyelik farklar bile odak akışını bozar.

---

## 💡 Çözüm

FocusJam herkesi aynı zaman çizelgesinde tutar.

* Bir kişi oturumu başlatır (Host)
* Diğerleri kod ile katılır
* Herkes aynı anda başlar

Geri sayım yok. Karmaşa yok. Sadece odak.

---

## 🚀 Mevcut Durum

🛠️ MVP aktif geliştirme aşamasında

* Gerçek zamanlı senkron sayaç
* Oda sistemi (Host / Kod ile katılım)
* Firebase tabanlı altyapı
* Reconnect sistemi (oturuma otomatik geri dönüş)

---

## 🧠 Vizyon

FocusJam sadece bir zamanlayıcı değil.

Bir **paylaşılan odak deneyimi**.

Planlanan özellikler:

* Deep Work Mode

* Ekip odak oturumları
